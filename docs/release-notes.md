# 1.0.1 交付补丁

沿用 1.0.0 的 SB1 FC1、E7 整段分类、实验 GP2 全部权重及计算；补齐模型结构、训练方法、数据规模／来源、指标口径、来源许可和交接文档。自有代码署名 Kscii，采用 MIT；R15、E1、E5 权重采用 CC BY-SA 4.0，具体文件与署名单列于 MODEL_LICENSES.md，完整许可随 wheel、源码和镜像分发。其余可授权自有权重采用 MIT，保留第三方条款。

2026-10-24 的文档修订将“录制结束后整段处理”标为推荐，并补充指标、静态图和走跑候选状态。发布的 wheel、标签及模式元数据保持原样；`whole_record.experimental=true` 的兼容说明见[模型手册](model.md#能力与运行方式)。这不是新的模型版本或准确率试验。

已执行 27 项库测试，以及 6 组新旧 wheel 的推理输出对比：分块／整段、整段符号适配开关、GP2 开关。除版本号和代码摘要外输出相等；运行文件只允许版本常量改变，197 个文件逐一核对。这是补丁一致性证据，不是新的准确率结果。

库版本与代码摘要进入任务指纹，因此不能恢复 1.0.0 的检查点。服务应先完成已有任务再升级；固定权重、输入语义、HTTP 与数据库兼容性分别判断。

新 wheel、sdist 及重建摘要在新 Release 的构建记录提供；1.0.0 的标签、历史报告和草稿资产保留。候选构建不代表公开发布已完成，许可决议以 provenance/source-license-review.json 为准。
